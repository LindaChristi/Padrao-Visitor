
# Padrão de Projeto Visitor

Exercício da disciplina de **Arquitetura e Projeto de Software**.

## Descrição

Este projeto apresenta um exemplo de utilização do padrão de projeto comportamental Visitor.

A aplicação simula um controle de estoque com três tipos de produtos:

- Madeira;
- Ferramenta;
- Equipamento.

O `ProdutoVisitor` percorre os objetos e exibe suas informações de acordo com cada tipo de produto.

## Execução

Para executar a aplicação, basta abrir o projeto na IDE e executar a classe `Principal`.

## Testes

O projeto possui testes unitários na classe `ProdutoVisitorTest`, utilizando JUnit.
